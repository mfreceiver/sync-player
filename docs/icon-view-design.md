# 图标浏览模式 — 设计方案

> 状态：待确认
> 日期：2026-04-09

---

## 1. 背景

当前文件浏览器仅有列表模式（`LazyColumn`），每行显示 40×40dp 缩略图 + 文件名/元数据 + 右侧环形进度。本方案新增「图标浏览模式」，以缩略图为视觉主体，提供更直观的批量浏览体验。

### 现有缩略图系统

| 项目 | 详情 |
|---|---|
| 生成方式 | `MediaMetadataRetriever.getFrameAtTime(0)` 原始帧，无缩放 |
| 存储路径 | `{app_data}/files/thumbnails/{videoId}.jpg` |
| 压缩质量 | JPEG 70% |
| 像素尺寸 | 与视频原始分辨率一致（未做 resize） |
| UI 框架 | Jetpack Compose + Material 3 (Dynamic Color) |

---

## 2. 需求摘要

1. 视图切换能力放入排序菜单，作为选项
2. 时长以标签形式显示在缩略图左下角
3. 已播放完成的进度条宽度占满，不需要对号表示
4. 允许用户手动切换 2-5 栏，不提供单卡片模式
5. 不显示文件名；用户可通过长按图标唤起视频卡片查看文件名
6. 文件夹只显示文件夹图标，不展示其中视频文件

## 5. 文件夹卡片

```
┌─────────┐
│         │
│         │
│   📁    │  ← FolderIcon 居中
│         │
│         │
│         │
└─────────┘
```

- 与视频卡片等高等宽，保持网格对齐
- 16:9 比例框内居中 FolderIcon
- 背景: `surfaceVariant`
- 不显示文件夹名称
- 单击进入文件夹，长按弹出上下文菜单（含文件夹名）

## 6. 排序菜单改造

在现有排序/筛选菜单底部新增「视图」区域：

```
点击 ↕ 按钮后展开:
┌─────────────────────────┐
│ 排序                     │
│  文件名 A→Z          ✓  │
│  文件名 Z→A             │
│  时长 短→长             │
│  时长 长→短             │
│─────────────────────────│
│ 筛选                     │
│  全部                 ✓  │
│  仅视频                  │
│  仅回收站                │
│─────────────────────────│
│ 视图              ≡  ▦  │  ← 列表 / 图标 切换按钮
│  栏数  [2] [3] [4] [5]  │  ← 仅图标模式时显示, 当前值高亮
└─────────────────────────┘
```

- 选择「列表」时隐藏栏数选项
- 选择「图标」时展开栏数选项
- 视图模式和栏数均持久化到 `UserPreferences`

## 8. 设计规格

### 8.1 布局参数

| 参数 | 值 |
|---|---|
| 容器 | `LazyVerticalGrid` + `GridCells.Fixed(N)`, N ∈ {2, 3, 4, 5} |
| 卡片圆角 | 12dp |
| 缩略图比例 | 16:9 (`aspectRatio(16f / 9f)`) |
| 卡片间距 | 水平 8dp, 垂直 8dp |
| 外边距 | 12dp |

### 8.2 进度条

| 参数 | 值 |
|---|---|
| 高度 | 3dp |
| 底色 | `onSurface.copy(alpha = 0.12f)` |
| 播放中填充色 | `primary.copy(alpha = 0.85f)` |
| 已完成填充色 | `successGreen` 全宽 |
| 位置 | 缩略图底部边缘，对齐底边 |

### 8.3 时长标签

| 参数 | 值 |
|---|---|
| 位置 | 缩略图左下角，进度条上方 |
| 字体 | `bodySmall` |
| 文字色 | 白色 |
| 背景 | `Color.Black.copy(alpha = 0.6f)` |
| 圆角 | 4dp |
| 内边距 | 水平 4dp, 垂直 2dp |

### 8.4 回收站角标

| 参数 | 值 |
|---|---|
| 位置 | 缩略图右上角 |
| 背景 | 20dp 圆形, `Color.Black.copy(alpha = 0.5f)` |
| 图标 | 12dp Delete 图标, `trashRed` |

### 8.5 Dark Mode

| 元素 | Light | Dark |
|---|---|---|
| 进度条底色 | `onSurface @ 12%` | `onSurface @ 20%` |
| 进度条填充 | `primary @ 85%` | `primary @ 85%` |
| 时长标签背景 | `Black @ 60%` | `Black @ 70%` |
| 回收站角标背景 | `Black @ 50%` | `Black @ 60%` |

## 9. 交互行为汇总

| 操作 | 列表模式 | 图标模式 |
|---|---|---|
| 单击视频 | 打开播放器 | 打开播放器 |
| 长按视频 | 弹出上下文菜单 | 弹出上下文菜单（含文件名+大缩略图） |
| 单击文件夹 | 进入文件夹 | 进入文件夹 |
| 长按文件夹 | 弹出删除确认 | 弹出删除确认（含文件夹名） |
| 排序/筛选 | 下拉菜单 | 下拉菜单（含视图切换） |

## 10. 技术实现概要

| 模块 | 方案 |
|---|---|
| 列表容器 | `LazyVerticalGrid` + `GridCells.Fixed(N)` |
| 卡片组件 | 新建 `VideoGridItem` / `FolderGridItem` @Composable |
| 进度条 | `Box` + `Alignment.BottomCenter` 叠加自定义 `Canvas` |
| 时长标签 | `Box` + `Alignment.BottomStart` 叠加 `Text` + 半透明圆角背景 |
| 回收站角标 | `Box` + `Alignment.TopEnd` 叠加 `Icon` + 半透明圆形背景 |
| 视图模式 | `BrowserViewModel` 新增 `viewMode` StateFlow，持久化到 `UserPreferences` |
| 栏数 | `BrowserViewModel` 新增 `gridColumns` StateFlow，持久化到 `UserPreferences` |
| 排序菜单扩展 | 在现有 `DropdownMenu` 末尾追加「视图」分组 |
| 文件夹混排 | `LazyVerticalGrid` 中文件夹项使用 `span = GridItemSpan(maxLineSpan)` 占满整行（若需保持网格对齐，则文件夹与视频同尺寸） |

## 11. 待确认问题

以下问题影响实现细节，请逐条确认：

### Q1. 非视频文件的处理

图标模式下，非视频文件（如 .srt, .nfo, .txt）是否显示？

- **A)** 显示，用 InsertDriveFile 图标占位（与无缩略图的视频类似）
- **B)** 不显示，图标模式自动过滤仅展示视频文件和文件夹

### Q2. 栏数记忆范围

栏数偏好（2/3/4/5）的作用范围？

- **A)** 全局统一（所有文件夹共用一个栏数设置）— 实现简洁
- **B)** 按文件夹单独记忆 — 切换文件夹时保留各自偏好

### Q3. 视图切换过渡

列表模式 ↔ 图标模式切换时是否需要过渡动画？

- **A)** 直接切换，无动画
- **B)** 淡入淡出过渡

### Q4. 时长标签与进度条的视觉整合

当前设计中时长标签在进度条上方，两者紧邻底部。是否合并为一个统一的底部叠加层？

- **A)** 分离：进度条贴底边 3dp，时长标签在其上方独立显示
- **B)** 整合：底部从下往上绘制渐变半透明底色，进度条在最底边，时长文字浮于渐变之上，形成统一的底部信息带

### Q5. 回收站文件的视觉降级

除了右上角 🗑 角标外，是否对回收站视频的缩略图施加额外的视觉降级效果？

- **A)** 仅靠角标区分，缩略图不做额外处理
- **B)** 施加半透明灰色遮罩（如 `Color.Gray.copy(alpha = 0.3f)`），使回收站视频看起来「褪色」
- **C)** 降低缩略图饱和度（灰度化处理）
